# Agent instructions

This is Fayreel's public documentation and release repository. `Src/Admin`,
`Src/App`, and `Src/Web` are separate private Git repositories. For component
work, read that submodule's agent instructions and run Git and GitHub commands
from its repository. Keep component issues and domain docs in that repository.

## Agent skills

### Issue tracker

Use GitHub Issues in `ceenreels/product-reels-fayreel` for this repository's work.
Before issue or spec work, read `Docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage labels. Before triaging or changing triage labels,
read `Docs/agents/triage-labels.md`.

### Domain docs

Use single-context domain documentation. Before exploring this repository or
changing domain terms or decisions, read `Docs/agents/domain.md`.
