# Agent instructions

This is Fayreel's public documentation and release repository. `Business`,
`Src/Admin`, `Src/App`, and `Src/Web` are separate private Git repositories.
Before working in a submodule, read its agent instructions and run Git and
GitHub commands from that repository. Keep its Issues and domain docs there.
Business research and planning belong in `Business`; product implementation
belongs in the corresponding component. Keep private findings out of public
Issues, PRs, and `Docs/`; only explicitly authorized public summaries belong here.

## Agent skills

### Issue tracker

For issue or spec work, read `Docs/agents/issue-tracker.md`.

Use GitHub Issues in `ceenreels/product-reels-fayreel` for this repository's work.
Before creating an implementation branch or editing repository files, including
for a request made directly in chat, follow
[Issue before changes](Docs/agents/issue-tracker.md#issue-before-changes).
The agent must publish or update the owning Issue first.

### Triage labels

Use the five canonical triage labels. Before triaging or changing triage labels,
read `Docs/agents/triage-labels.md`.

### Domain docs

Use single-context domain documentation. Before exploring this repository or
changing domain terms or decisions, read `Docs/agents/domain.md`.
