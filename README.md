# Fayreel documentation and downloads

Each project has its own fixed release tag. Application source and credentials are not published here.

## Documentation

- [Documentation home](https://ceenreels.github.io/product-reels-fayreel-release/)
- [Setup documentation](https://ceenreels.github.io/product-reels-fayreel-release/Documentation/)
- [Admin user guide](https://ceenreels.github.io/product-reels-fayreel-release/How-To-Use/)

The repository root contains `index.html`, `Documentation/`, and `How-To-Use/`. Open the root `index.html` locally to browse both guides with their accompanying assets.

## Publishing

GitHub Pages publishes automatically from the **`ceen` branch, `/ (root)`**. Push documentation changes to `ceen`; GitHub's built-in Pages deployment updates the website. Check the `pages build and deployment` run in Actions for its result.

The root `.nojekyll` file serves the documentation as static files without Jekyll processing. No build tools or additional secrets are required. The fixed project Release tags continue to provide application downloads separately.
